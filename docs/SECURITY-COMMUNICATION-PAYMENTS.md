# 管理员验证码、通信与支付接入

## 管理员登录验证码

管理员首次登录以及未开启登录验证码时，只校验账号和密码。管理员在“安全与通信”页主动配置身份验证器或邮箱验证码并确认后，后续登录才会出现“验证码”输入页；登录页不展示 2FA/MFA 等内部术语。

身份验证器密钥和 SMTP 密码使用 `SESSION_SECRET` 派生密钥进行 AES-256-GCM 加密；恢复码仅保存 HMAC 摘要。验证码 challenge 短时有效、限制尝试次数并防止重复使用。详细接口见 [ADMIN-MFA-API.md](ADMIN-MFA-API.md)。

## 域名邮箱与手机验证码

域名邮箱通过管理后台配置标准 SMTP TLS/STARTTLS。保存仅代表凭据已落盘；只有测试邮件被 SMTP 服务真实接受后，页面才标记“已测试”。生产环境不允许明文 SMTP。

手机验证码支持阿里云短信和腾讯云短信正式 API。需要先完成企业实名认证、短信资质、签名与模板审核，再在后台保存最小权限访问密钥。注册与后台测试在服务商拒绝、超时或未配置时明确返回错误；登录和找回密码为防止枚举账号，统一只提示“如账号存在且通道可用将会发送”，不会宣称已经发送。用户接口见 [USER-VERIFICATION-API.md](USER-VERIFICATION-API.md)。

当前验证码和限流状态保存在单个进程内存；首发单实例可以使用。横向扩容前必须迁移到 Redis 等共享存储。

## 微信支付与支付宝

后台“支付与订单”页可配置：

- 微信支付 Native API v3：AppID、商户号、商户 API 证书序列号、商户私钥、微信支付公钥/平台证书公钥、API v3 密钥和 HTTPS 通知地址。
- 支付宝电脑网站支付：应用 AppID、卖家 ID、应用私钥、支付宝公钥、HTTPS 异步通知地址和可选同步返回地址。

凭据只以加密形式落盘且不回显。启用前执行的是本地格式、签名和验签自检，不会制造交易。管理员可在同一页面维护服务端权威套餐的名称、原价、发放点数、有效天数、在售状态和限时优惠；优惠价仅在配置的开始/结束时间内生效。每笔订单保存下单时的价格与权益快照，后续改价不会改变历史订单。

浏览器提交的金额不作为结算依据；若浏览器展示价已过期，服务端返回最新报价并拒绝直接下单。生产环境默认要求用户向当前绑定手机号或邮箱获取一次性支付验证码。只有官方异步通知通过签名、应用/商户、订单号和金额校验后，订单才可进入“已支付”。

已支付订单会按订单号幂等发放会员有效期与教案生成点数。为避免尚未实现的升级折算让用户损失有效天数，新购买的任意付费套餐会从现有最后一段付费权益到期日后顺延；当前阶段不做立即升级或差价补款。若订单状态已经保存但权益存储暂时失败，回调返回失败并将履约标记为“需重试”；支付平台重复通知时会再次发放，用户点数不会重复增加。套餐均为一次性购买，不会自动续费。

当前已经闭环：权威套餐与限时直减、手机/邮箱支付验证码、微信 Native 下单、支付宝电脑网站支付、通知验签、金额校验、订单幂等和会员/点数发放。尚未实现的是独立优惠码与人群规则、微信/支付宝主动查单、定时对账、关单、退款申请与退款通知、发票、拒付/风控。特别是网关超时或响应验签失败的微信订单会保持“待核实”，在主动查单完成前禁止人工猜测成功；退款也不能仅在本地改状态，必须接官方退款 API、退款回调和已消费点数的冲正/欠额政策。

正式联调必须使用已审核的企业商户资料、公网 HTTPS 回调域名和服务端权威套餐价格；离线测试不会连接真实支付网关。

接口与状态边界见 [支付与会员接口](PAYMENT-MEMBERSHIP-API.md)。
